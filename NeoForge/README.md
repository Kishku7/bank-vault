**NeoForge** loader builds of Bank Vault for the Minecraft 26.2 (pre-release) line. Client + server mod.

```
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/bank-vault-*.jar`. Part of the [`26.2` branch](../README.md).
