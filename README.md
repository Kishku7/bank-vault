# Bank Vault - 26.1

Source for Minecraft 26.1 (26.1 through 26.1.2), organized loader-on-top: `Common/` (shared code), `Fabric/`, `Forge/`, `NeoForge/`, each with a subfolder per Minecraft version.

These are standalone builds (no Architectury on 26.x).

### `Fabric/`

- [`26.1.2`](Fabric/26.1.2/) - Minecraft 26.1 - 26.1.2

### `NeoForge/`

- [`26.1.2`](NeoForge/26.1.2/) - Minecraft 26.1 - 26.1.2

Client + server mod (Java 25). [Modrinth](https://modrinth.com/mod/bank-vault) - [Releases](https://github.com/Kishku7/bank-vault/releases) - overview: [`main`](https://github.com/Kishku7/bank-vault).
